Non-negotiable design principles

Digest over tag
Tags can move; verification binds to immutable content.
Build success ≠ runtime trust
The cluster verifies the artifact independently.
SBOM ≠ security certification
Inventory supports analysis; it does not prove safety.
Exceptions expire
Risk acceptance needs an owner, rationale and review date.
