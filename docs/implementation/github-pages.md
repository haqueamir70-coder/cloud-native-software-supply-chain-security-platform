# Enable the interactive architecture preview

The interactive architecture is copied to `docs/index.html`, so GitHub Pages can serve it directly from the repository's documentation folder.

## One-time setup
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/docs**, then save.
4. Wait for GitHub Pages to publish the site.

Expected preview URL:

`https://haqueamir70-coder.github.io/cloud-native-software-supply-chain-security-platform/`

When you change `docs/architecture/interactive.html`, copy the updated file to `docs/index.html` so the published preview stays in sync. The source file remains available in the architecture folder.
